# Main decisions for the layering unit (wp1)

Binding decisions from main (implement in the plan; if code forces a change, write an explicit amendment with the reason):
STATIC LINT (recipes feature; new files src/recipes/lint-layering-low.tool.ts, lint-layering-harmony.tool.ts, lint-layering-rhythm.tool.ts with colocated tests; invoked from lint.tool.ts; all severity "warning" so --strict fails with exit 6):
L1 generic/low_end_overlap: two distinct audible pitched tracks each with notes at MIDI <= 46 (Bb2, ~116.5 Hz) sounding simultaneously (duration-weighted, event duration clamped at the next same-track onset as the mixer does) for >= 25% of a section occurrence's duration; ignore tracks with gain <= -24 dB; one finding per section occurrence (first) with track ids. Source: SOS Mixing Bass (choose one main low-end source), iZotope kick/bass (one winner at a time). Threshold values are I (documented rationale).
L2 generic/low_chord_spacing: within one non-bass pitched track (not 808/bass), simultaneous note pairs with simple interval 1..11 semitones whose lower note is below the low-interval-limit table (scientific pitch, C4=MIDI 60): m2 52 (E3), M2 51 (Eb3), m3 48 (C3), M3 46 (Bb2), P4 46 (Bb2), TT 47 (B2), P5 34 (Bb1), m6 43 (G2), M6 41 (F2), m7 41 (F2), M7 41 (F2). Warn once per track with first bar and the pair. Source: Berklee-style low interval limit table as circulated by Sweetwater and discussed by Robin Hoffmann and Music SE; label as guidance.
L3 generic/low_pan: an 808 or bass track, or any pitched track with >= 25% of its notes at MIDI <= 46, with |pan| > 0.1. Source: EDMProd mono below 120 Hz, iZotope M/S, Mastering The Mix width mistakes.
L4 generic/kick_bass_unducked (house and techno only): >= 50% of kick onsets (drum atom bd) fall while a bass/808 note is sounding or starting within +-30 ms, and that bass track has no duck whose 'by' track contains bd events. Trap/drill/boom bap/lofi are exempt (deliberate 808/kick layering; documented deferral). Source: Attack rolling techno bass (sidechain, kick space), SOS (2-3 dB duck), EDMProd sub (50-150 ms release).
L5 generic/register_collision: two focal pitched tracks among instruments lead, bell, pluck, keys (pad, 808, bass excluded) in the same section occurrence of >= 2 bars, median MIDI within 7 semitones, and >= 75% of the sparser track's onsets land in the same 8th-note slot as an onset of the other. Source: EDMProd call and response (contrast pitch/octave), EDMProd production pyramid (about three focal elements). Thresholds I.
L6 generic/sub_floor: any pitched note below 30 Hz (MIDI <= 22). Source: Splice/MusicRadar roll-off below 30-40 Hz, EDMProd sub reproduction limits.
Deferred with reasons: trap/drill kick-808 coincidence rule, melodic layer count, relative-gain lint (gain does not predict stem level per synth), per-instrument HPF (no field in Song v1), per-section band shares (flow discards raw band power).
ANALYZE (new src/analyze/balance-warnings.tool.ts + test; analyze.tool.ts passes opts.song?.genre; new warning codes are additive; keep observed/threshold shape):
A1 LOW_END_DOMINANCE keeps its code but its sub+low threshold becomes genre-aware: trap, drill_uk, drill_ny, house, techno 0.92; boom_bap, lofi_hiphop 0.85; unknown genre and WAV-only keep 0.55 (behaviour documented). Message names the genre guide. Source: TrackScore electronic band shares (sub+bass 76-89% linear power, same band edges as music2), iZotope TBC (bass-heavy genres carry more low end), slope model in evidence/sol-tonal-balance.md; 0.92 = observed max + margin (I). Record the pre-change baseline in evidence/baseline-bands-1da22d7.txt.
A2 LOW_MID_BUILDUP: lowMid (250-500 Hz) share > 0.25 for all genres and WAV-only. Source: TrackScore low-mid 3-7%, slope model ~9-10%, Elowsson-style pop LTAS ~22% in music2 bands; 0.25 sits above the pop mean (I).
A3 SUB_WITHOUT_BODY: sub/(sub+low) > 0.65 and sub+low > 0.5. Source: iZotope 808 harmonics/saturation for translation, MusicRadar 808 saturation; ratio is I.
A4 HIGH_END_THIN: presence+air < 0.02, lofi_hiphop exempt (rolled-off by design, NI lo-fi drum LPF ~3.1 kHz); WAV-only applies. Source: TrackScore highs 6-16 kHz 2-4% plus 2-6 kHz ~4%; I threshold.
Warnings order: existing warnings, then A1-A4 in that order, then flow warnings; they appear in analysis.json, analysis.md, overview verdict priority (after CLIPPING, LUFS_OFF_TARGET) and summary.
WP3 (cards/examples/skill): all examples except intentional fixtures minimal.song.json and wrong-genre.song.json must pass strict lint and analyze without A1-A4; fix by arrangement and mix edits (808 gain/drive, hats/lead gain, chord voicing up an octave, bass duck by kick for house/techno), never by threshold changes. Card starter songs: strict lint clean with the new rules (house/techno starters get bass duck by kick; voicings respect L2). Changing the four core eval examples makes the archived overview-eval hashes historical; record that. docs: new skills/music2/references/layering.md (cited; band owners table; low-end ownership; low-mid voicing table; mids/presence pocket; stereo; gain staging conventions labelled as conventions; genre balance table from evidence), mixing.md update, SKILL.md 'layering pass' step (lint -> analyze bands -> fix order), docs/cli.md warning list, str_func recipes/analyze, CHANGELOG Unreleased. e2e: examples test asserts absence of A1-A4 and new lint ids; a synthetic bass-heavy fixture (tests only) still fires A1 for trap (c-4).
