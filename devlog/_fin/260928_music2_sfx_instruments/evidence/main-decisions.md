# Main binding decisions (wp1)

Accept architect F1-F9 (evidence/architect-proposal.md) with these specifics:

D1 In-song SFX: new built-in voice 'sfx', kind drums. Atoms: riser (noise riser), pitchriser (detuned polyBLEP saws with exponential pitch ramp), downlifter, impact, whoosh, revcymbal, noisebuild, subdrop, zap, crackle; optional ':0..3' variant (modulo 4) selecting a documented timbre variant. Event span = full weighted pattern slot (gate ignored for sfx); '@n' weights set relative length; render exactly the event span (no tail beyond it except impact/subdrop decay which may ring until their T60 bound but never past the render frame count). Track params (numeric, validated): riserSemitones 19 [0..36], sweepFromHz 250 [100..2000], sweepToHz 8000 [1000..16000], pitchHz 220 [55..880], impactDecay 0.8 [0.2..3], crackleRate 8 [1..30], noiseColor 0 [0..1 int] (0 white, 1 pink). Snare build stays a pattern technique (documented, no atom). Formulas and oracles: evidence/sol-synthesis-methods.md section 1.
D2 VoiceSpec gains optional sampleNames; drums declares its existing names; render validation looks up the voice's declared names (kit: manifests unchanged). Lint rhythm predicates (isKick/isBackbeat/isHat and percussion discovery) must only treat instrument 'drums' or kit: samples as kit roles, never 'sfx'.
D3 New insert effect 'tapestop' in src/render/fx: params startBar 1 [1..1024 int] (1-based absolute song bar), beats 2 [0.25..16]; slows pitch and time together from that bar with v(u)=(1-u)^2 and a 15 ms end fade; FxContext gains optional startSeconds (render start offset, for --bars) — absent means 0 — and optional secondsPerBar (meter-aware bar length, required by tapestop); a partial render pre-rolls any tape-stop track from bar 0 through the crop end and then crops (audit round 1); legacy paths untouched.
D4 Standalone command 'music2 sfx' in a new feature src/sfx/ (sfx.schema.ts, presets.tool.ts, generate.tool.ts, index.ts, colocated tests) plus src/cli/commands/sfx.ts: --preset (required), --seed (uint32, default 1), --seconds (0.05..30, default per preset), --sample-rate 44100|48000 (default 44100), --params k=v,... (numeric, validated per preset; unknown/duplicate/non-finite/out-of-range -> E_INPUT exit 2), -o/--out (required, existing file -> E_ACCESS exit 4), --json one envelope. Presets: the ten in-song SFX (sharing the same synthesis kernel as the sfx voice) plus game/UI presets pickup, laser, explosion, powerup, hit, jump, blip, alert, click, confirm, error (sfxr-style parameter vocabulary implemented clean-room from public parameter descriptions only; ranges from evidence/sol-synthesis-methods.md section 2; seeded per-preset randomization with fixed PRNG draw order). Output: 16-bit stereo WAV (mono duplicated, except whoosh may pan-sweep) through audio-io writeWav with seeded dither, plus <basename>.sfx.json sidecar (stable key order: generator version, preset, seed, seconds, frames, sampleRate, resolved params). Deterministic bytes for same inputs.
D5 New pitched voices (notes kind), each its own *.tool.ts + test under src/render/voices/ (subfolders allowed: keys/, orchestral/, mallets/, strings/, winds/ only if structure audit allows; otherwise flat): piano, epiano, strings, brass, organ, marimba, vibraphone, glockenspiel, kalimba, guitar (param type 0 nylon/1 steel), flute, choir (param vowel 0 a,1 e,2 i,3 o,4 u). Parameters and oracles per evidence/sol-synthesis-methods.md section 3 (use its defaults/ranges; drawbars as nine params d16,d513,d8,d4,d223,d2,d135,d113,d1 0..8). Output level normalized comparable to existing voices (sustained RMS within +-3 dB of pad at velocity 0.8 for sustained voices; peak <= 1 before mix).
D6 drums voice gains param kit 0 [0..4 int]: 0 classic (current code path, byte-identical, including explicit kit 0), 1 909-style, 2 808-style, 3 acoustic-ish, 4 lo-fi (post-crush). New branches only for kit >= 1.
D7 Lint: register_collision focal set adds piano, epiano, guitar, flute, brass, marimba, vibraphone, glockenspiel, kalimba (strings, choir, organ are bed voices like pad). Low-end rules already cover pitched voices. No new lint ids required beyond classification; sfx tracks never count as groove/kick/snare/hat layers.
D8 Legacy: all existing digest tests (mixer drill WAV, tests/e2e/legacy-render, voice PCM digests) must pass unchanged; add a test that drums with kit 0 equals omitted kit.
D9 Docs: skills/music2/references/sfx.md (NEW: in-song SFX atoms, lengths with @n, placement practice from evidence/aside-notes A1 with URLs, tapestop, music2 sfx presets table with params), instruments.md rows for all new voices and drums.kit, docs/cli.md sfx command, docs/song-format.md sfx track example, devlog/str_func/sfx.md + index, render.md, cli.md, song.md. Examples (wp4): at least three new example songs using new instruments and SFX (e.g. a K-pop/pop song with piano, strings, pitchriser/impact; a lo-fi with epiano, crackle, vibraphone; a cinematic/orchestral cue with strings, brass, choir, timpani-like impact; a game loop with marimba/kalimba and a game SFX sequence) that validate, strict-lint clean and analyze without balance warnings; plus standalone sfx examples in docs.
D10 Performance: each 10 s preset renders < 2 s; a 3-minute song with 10 tracks including new voices renders within the existing budget; measured and recorded.
