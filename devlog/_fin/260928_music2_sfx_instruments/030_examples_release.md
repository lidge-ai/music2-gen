## 1. Example-song contracts

Each new song is source JSON with `version:1`, explicit seed, BPM/key, complete tracks/sections/arrangement, and a build-to-resolution contrast. **Omit** `genre` for pop/cinematic material without a fitting recipe (it resolves to `null`); set `lofi_hiphop` for the lo-fi song. Explicit JSON `genre:null` is invalid because the source schema permits a string, while the resolved type is nullable (`src/song/song.schema.ts:45-52,95-100,345-349`). An invented genre string would create `generic/unknown_genre` and fail strict lint (`src/recipes/lint.tool.ts:95-109`; `src/recipes/lint-generic.tool.ts:50-57`). In the test harness, allow `null` as the expected resolved genre and compare `source.genre ?? null` (`tests/e2e/examples.test.ts:18-37,93-103`). The songs must be original; do not clone an existing example wholesale. Keep music and SFX tracks separate so `sfx` does not masquerade as groove (`src/recipes/lint-geometry.tool.ts:57-65`; `devlog/_fin/260928_music2_sfx_instruments/020_instruments.md` §3). Use a transition section override or `null` mute and confirm actual onset times with `events`, because a section can override the track's base pattern (`src/song/timeline.tool.ts:45-66`).

For the required `riser@3 impact@1` example, the weighted slots occupy 75% and 25% of each active bar. The first `impact` therefore lands on beat 4 of 4/4, **not** the next bar's downbeat. A hook-section override with a one-atom `impact` can put a separate hit at the hook start; a separate `pitchriser` layer covers the requested pitched rise. `@3` is relative, not seconds (`src/pattern/query.tool.ts:24-49`); document both onsets accurately. In the orchestral cue, let the one-atom `revcymbal` fill the preceding bar and put a one-atom `impact` at the next bar start. Source guidance V supports riser/snare layer roles and reverse-cymbal lead-ins; exact downbeat alignment is an I production choice (`devlog/_fin/260928_music2_sfx_instruments/evidence/aside-notes/A1_transition_sfx.md:53-59,103-106,112-121`). Snare acceleration is written with `sd` patterns, not a new SFX name (`devlog/_fin/260928_music2_sfx_instruments/evidence/sol-synthesis-methods.md:23`).

Example acceptance is stronger than CLI success alone: each file must `validate`, show intended section events, exit zero under `lint --strict`, render successfully, and yield zero A1–A4 balance warnings in song-backed `analyze`. Existing E2E harness checks zero balance warnings (`tests/e2e/examples.test.ts:88-128`); add the new cases there. If one fails, revise note register, pattern density, gain, SFX placement or high support and rerender; do not lower product thresholds (`docs/cli.md:27`; `devlog/_fin/260928_music2_layering/010_layering_checks.md:94-98`). Use 44.1 and 48 kHz fixtures for the new voice kernels; example audio files go to temporary output locations only.

| Song | Required new material | Arrangement/QA oracle |
| --- | --- | --- |
| `pop-transition` | piano, strings, `riser`, `pitchriser`, `impact` | Beat-4 impact and next-hook downbeat are separate events; piano/strings avoid low voicing collision and A1–A4. |
| `lofi-textures` | epiano, vibraphone, `crackle`, synthetic drum kit 4 | Crackle remains quiet; note tails do not hide percussion; no low-mid buildup warning. |
| `cinematic-cue` | strings, brass, choir, `revcymbal`, `impact` | Reverse rise ends on accent; focal brass has separate register/rhythm from other lead. |
| `game-spark-loop` (if included) | marimba, kalimba, `zap` or `whoosh` | Loop seam remains clean, game cue stays a song SFX atom; UI one-shots exported separately. |

## 2. Public documentation and standalone recipe

Explain that it writes `out/music2-pickup.wav` and `out/music2-pickup.sfx.json`, with `artifacts` holding both. Include a second parameterized transition example, e.g. `--preset riser --seconds 2 --params sweepFromHz=250,sweepToHz=8000`; keys must match the final allowlist. Document that an existing WAV **or sidecar** yields `E_ACCESS` exit 4; invalid preset/param/rate/seed/seconds yields `E_INPUT` exit 2. `--json` is one object, and the sidecar key order/version are stable (`src/cli/registry.ts:30-36`; `src/audio-io/wav.tool.ts:102-133`).

The SFX guide differentiates the in-song atom universe (ten names, `:0..3` modulo variants) from the standalone preset universe (those ten plus eleven game/UI names). Research hygiene: use `devlog/_fin/260928_music2_sfx_instruments/evidence/aside-notes/A1_transition_sfx.md:112-125` to link cited public production practice and `devlog/_fin/260928_music2_sfx_instruments/evidence/sol-synthesis-methods.md:78-96` for clean-room DSP references.
