## 1. Song voice and time contract

`sfx` is sample-name-shaped, but synthesized: use `{ "id":"transition", "kind":"drums", "instrument":"sfx", "pattern":"riser@3 impact@1", "params":{"noiseColor":0} }`. The accepted names are **riser, pitchriser, downlifter, impact, whoosh, revcymbal, noisebuild, subdrop, zap, crackle**. An omitted suffix is variant 0; `:0..3` names four stable timbres. Parsed nonnegative integer indices are reduced modulo four (`src/pattern/values.tool.ts:26-31`); document e.g. `riser:5` = variant 1. A malformed suffix still fails pattern syntax. Unknown built-in atom names fail on render with `E_SCHEMA`; `validate` continues to check grammar, not instrument-specific names (`src/song/song.schema.ts:268-287`; `src/render/render.tool.ts:12-27`).

The slot is the full duration after `@n` weighting. `riser@3 impact@1` means 3/4 and 1/4 of the pattern cycle; `@3` does **not** mean three seconds. Song tempo and meter convert slots to seconds (`src/pattern/query.tool.ts:24-49`; `src/song/timeline.tool.ts:55-66`). For riser/pitchriser/downlifter/whoosh/revcymbal/noisebuild/zap/crackle, synthesize exactly through the event slot and stop. Impact/subdrop may decay past the slot to the configured T60 bound, never beyond `ctx.frames`; this is the only SFX tail exception. Repeat/section boundaries must not create unbounded tails. Track `gate` remains accepted but ignored by `sfx` only. Because `selectEvents` currently gives drum events `stopFrame:frames`, the SFX adapter must use `startFrame + gateFrames`, not `stopFrame`, as its ordinary bound (`src/render/mixer.tool.ts:24-60`).

## 2. Transition kernel and oracles

All waveform equations and numeric timbres below are **I** product designs from `devlog/_fin/260928_music2_sfx_instruments/evidence/sol-synthesis-methods.md:7-26`, not claims of exact hardware sound. Public filter/oscillator methods are in its R1–R3 ledger (`devlog/_fin/260928_music2_sfx_instruments/evidence/sol-synthesis-methods.md:78-83`). Use event-addressed `fnv1a32`/`mulberry32` (`src/render/voices/drums.tool.ts:1,39`; `src/render/mixer.tool.ts:36-40`) and fixed draw order. Clip oscillator/filter frequency below `0.45 Fs`, bound state/gain before output, check every sample finite and peak ≤1 before mixing. Do not use `Math.random`, wall time, or a global RNG.

| Atom | Proposed synthesis and duration behavior | Concrete test oracle |
| --- | --- | --- |
| `riser` | Seeded white/pink noise → moving band-pass; `fc=from*(to/from)^u`, gain `sin²(πu/2)`; taper final 5 ms if exposed. | Late 100 ms RMS exceeds early by >8 dB and late centroid rises; same-seed PCM bytes repeat. |
| `pitchriser` | 3–7 detuned polyBLEP saws; `f=pitchHz*2^(riserSemitones*u/12)`, gain `u^1.5`; omit over-Nyquist partials. | Stable-window terminal pitch within 2% of formula, increasing RMS, finite max sweep. |
| `downlifter` | Descending swept noise/filter and falling amplitude; choose direct form without full reversal buffer. | First-window centroid > last; RMS falls; no state grows at long length. |
| `impact` | Early 1–3 ms click/filtered noise plus sub sine descending about 150→40 Hz, `A_T60(t;impactDecay)`. | First 20 ms pitch >100 Hz; at 150–250 ms near 40±5 Hz; later RMS falls; tail ends by bound/frame cap. |
| `whoosh` | White noise, band-pass 300→6000→300 Hz, HP ~150 Hz, `sin^1.5(πu)` gain; mono in voice. | Middle centroid > both ends; exact slot length; no invented stereo in mono voice. |
| `revcymbal` | Metallic/noise band 4–10 kHz, convex gain `u²`, hard landing at end of slot. | Final 100 ms RMS > first by ≥10 dB; no nonzero sample after landing. |
| `noisebuild` | White/pink noise and progressively brighter/louder filter envelope, distinct repeated pulses inside slot. | Windowed RMS/centroid trend upward; pulse count and onset indices repeat by seed; no one-shot tail. |
| `subdrop` | Early low-band descending sine with brief attack and `impactDecay` T60. | Low-band energy concentrated near onset; descending estimated pitch; bounded ring-out. |
| `zap` | Band-limited pulse/square, exponential pitch fall ~1800→180 Hz. | First pitch > final, each within 10% of analytic trajectory; no Nyquist alias fold. |
| `crackle` | Quiet hiss plus seeded Poisson click arrivals `Δt=-ln(max(U,ε))/crackleRate`, 0.3–3 ms clicks. | Same seed click indices identical; other seed differs; 60 s count within λT±5√(λT); `U≈0` finite. |

Variants 0..3 change only documented timbre settings (noise color/brightness, detune/filter Q, or transient mix), never slot length or seed addressing. The `sfx.md` card states their exact mappings once implemented. Test all ten × four variants, at both sample rates, including `riser:5` modulo behavior. The synthesized approximations need listening review, but spectral/temporal assertions are the hard automated quality gate. SFX source material must follow Sol's clean-room ledger (`devlog/_fin/260928_music2_sfx_instruments/evidence/sol-synthesis-methods.md:3-5,28-30`); `devlog/_fin/260928_music2_sfx_instruments/evidence/aside-notes/A2_EXCLUDED.md:3` records that the excluded note came from code inspection, so **do not use its implementation mappings or source as implementation input**. Use only public parameter descriptions and independent Sol equations. No binding decision is changed by this evidence hygiene.

## 3. `tapestop` insert

`{"type":"tapestop","startBar":9,"beats":2}` is a track insert. `startBar` is a 1-based absolute song bar; `beats` is quarter-note beats (seconds = `beats*60/bpm`). Convert bar start to absolute seconds as `(startBar-1)*FxContext.secondsPerBar` (meter-aware; 3/4 bars are 3 beats long), then to local samples by subtracting `FxContext.startSeconds`; under the mixer pre-roll rule `startSeconds` is 0 for any tape-stop track, so the processor sees absolute song time. At/after the start, copy the unprocessed source from `n0` to the buffer end into a snapshot, then read from that snapshot (never from the buffer being written) with source position `p[n+1]=p[n]+(1-u)^2`, `u=clamp((n-n0)/(T*Fs),0,1)`, interpolate each channel, and fade the last 15 ms to zero. Preserve samples before the start; after stop completion output silence for the affected insert buffer. This is variable-speed resampling, with pitch slowing too (`devlog/_fin/260928_music2_sfx_instruments/evidence/sol-synthesis-methods.md:24`; `devlog/_fin/260928_music2_sfx_instruments/evidence/aside-notes/A1_transition_sfx.md:69-75`).

| Parameter | Default | Inclusive accepted range | Source |
| --- | ---: | --- | --- |
| `startBar` | 1 | 1..1024 integer | D3 I UI contract (`devlog/_fin/260928_music2_sfx_instruments/evidence/main-decisions.md:7`). |
| `beats` | 2 | 0.25..16 | D3 I UI contract (`devlog/_fin/260928_music2_sfx_instruments/evidence/main-decisions.md:7`); overrides Sol provisional 0.8 s duration. |

If the stop window falls wholly outside `--bars`, the insert is an exact bypass before its start or silence after its completion, as appropriate. If a partial render starts inside an active stop, its read pointer may refer to source before the requested crop. The mixer pre-roll rule in the file map handles this: a tape-stop track in a partial render is rendered and processed from song bar 0 to the crop end, then cropped, so earlier inserts, still-sounding notes and the stop's read pointer all see the same source as the full render. Passing `startSeconds` alone is insufficient. Test full-song versus matching crop for a track with a note that starts before the crop and sustains into the stop, in both 4/4 and 3/4. Keep this additional work confined to songs using tapestop and `--bars`; old no-insert bar renders retain their exact path. Existing effects/master path must have unchanged bytes (`src/render/fx/fx.schema.ts:60-63`; `src/render/mixer.tool.ts:284-292`). A stop beginning beyond song length is valid and has no audible effect.

## 4. Standalone generator and CLI contract

`music2 sfx --preset pitchriser --seed 1 --seconds 2 --sample-rate 44100 --params riserSemitones=12,pitchHz=180 -o cue.wav --json` uses no positional song. Exact output frames are `round(seconds*sampleRate)` per architect F3 (`devlog/_fin/260928_music2_sfx_instruments/evidence/architect-proposal.md:17`); store realized seconds `frames/sampleRate` in sidecar/JSON so frame count and displayed duration agree. Required preset/out; omitted seed is uint32 `1`; omitted seconds uses the preset default; sample rate is 44100 or 48000, default 44100; explicit seconds finite in 0.05..30. Reject RIFF overflow before allocation. Ten transition presets reuse in-song synthesis and names; UI presets are `pickup`, `laser`, `explosion`, `powerup`, `hit`, `jump`, `blip`, `alert`, `click`, `confirm`, `error` (D4, `devlog/_fin/260928_music2_sfx_instruments/evidence/main-decisions.md:8`).
