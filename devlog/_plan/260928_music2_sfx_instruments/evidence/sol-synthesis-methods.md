# Offline synthesis methods: transition, game SFX, and instruments

## Status and contract

This is a clean-room implementation recipe, not a transcription of an existing synthesizer. Sources below establish acoustical principles, public parameter meanings, or published measurements. **Every range/default not explicitly attributed to a measurement is a proposed starting preset**, to be tuned by listening. In particular, the “909/808” labels mean recognizable approximations, not circuit equivalence. Do not inspect or port sfxr/bfxr/jsfxr implementation code, nor GPL/AGPL code. Runtime dependencies: zero.

Render each voice to a **mono `Float32Array`** at `Fs ∈ {44100, 48000}`; the caller mixes, clips/limits, and pans (including leftward whooshes). Inputs are seconds/Hz/cents/dB, with `N = ceil(duration * Fs)` samples. Use a fixed song seed and `src/shared/prng.tool.ts`; derive a stable per-event stream from `(songSeed, trackId, eventId)` so call order does not alter output. No `Math.random` or wall clock. Let `t=n/Fs`, `u=clamp(t/T,0,1)`, phase `φ[n+1]=φ[n]+2π f[n]/Fs`, and `osc=sin φ` unless specified. Use `A_T60(t)=10^(−3t/T60)`; stop/zero a voice when its envelope is below −80 dB. Clamp all filter frequencies to `[20,0.45 Fs]`, all denominators away from zero, gains to a finite headroom budget, and output samples to finite numbers. Skip partials at/above `0.45 Fs`; for bright saw/square use band-limited harmonic sums or polyBLEP, especially for pitch sweeps. Fixed-point sample positions (or double precision phase) avoid drift. [R1,R2,R3,R4]

Shared filter: use the W3C/RBJ digital biquad with `ω=2πfc/Fs`, `α=sin(ω)/(2Q)`, `a=(1+α,−2cosω,1−α)`; LP numerator `((1−cosω)/2,1−cosω,(1−cosω)/2)`, HP `((1+cosω)/2,−(1+cosω),(1+cosω)/2)`, constant-peak BP `(α,0,−α)`. Divide all coefficients by `a0`, then `y[n]=b0x[n]+b1x[n−1]+b2x[n−2]−a1y[n−1]−a2y[n−2]`. For moving cutoff/Q, update coefficients every 32 samples and interpolate coefficients (or interpolate cutoff then recalculate) to avoid zipper noise; check stability as `|poles|<1`. `Q=0.707` default LP/HP; `Q=0.5–8` BP. Pink option: 8–12 Voss–McCartney octave-held random rows plus a fresh white row; normalize by row count. It is approximate 1/f, while white is `2U−1`. [R1,R2]

## 2. Game SFX generator: parameter vocabulary, independent implementation

The original sfxr README describes waveform, envelope, start/min frequency, slide/delta slide, vibrato, pitch change, square duty, repeat, phaser and LP/HP filters, but **not** the following physical-unit mapping or preset ranges. Those are this project's independent design. No sfxr/bfxr/jsfxr code was read or used. [R4]

Rendering order: phase oscillator → attack/sustain/punch/decay gain → short moving-delay “phaser” mix → resonant LP → HP → output gain. Shapes: sine, band-limited saw, band-limited square/pulse, or held/noise samples; duty `d(t)=clamp(d0+dSlope·t,0.05,0.95)` with `d0=0.5 [0.1,0.9]`, `dSlope=0 [−2,2]/s`. Frequency in Hz follows `log2 f(t)=log2 fstart + s·t + 0.5a·t² + (vDepth/1200)sin(2πvRate·t) + jump·1[t≥tArp]/12`, where slide `s=0 [−8,8] oct/s`, delta slide `a=0 [−20,20] oct/s²`, vibrato `vDepth=0 [0,100] cents`, `vRate=5 [1,12] Hz`, arpeggio `jump=0 [−24,24] st`, `tArp=0.08 [0,0.5] s`. Clamp `f` to `[20,0.45Fs]`; **terminate**, rather than clamp-and-continue, when a downward trajectory crosses `fmin=40 [20,1000] Hz`. `fstart=440 [40,4000] Hz`. [R3,R4]

Envelope: piecewise attack `t/A`, sustain `1+p(1−(t−A)/S)`, decay `1−(t−A−S)/D`; `A=0 [0,0.5]`, `S=0.10 [0.01,1]`, punch `p=0 [0,1]`, `D=0.15 [0.01,2]` seconds. Clamp nonnegative. Repeat every `R=0 [0.03,0.5] s` resets **pitch/duty trajectory and arpeggio clock only**, preserving envelope and filter states. Phaser is a moving-delay comb `y=x+m·x[n−d(t)]`, `m=0 [−0.8,0.8]`, `d=2..20 ms`, sweep `−10..10 ms/s`; fractional read by linear interpolation. LP cutoff `fc=12000 [100,0.45Fs] Hz`, resonance `Q=0.707 [0.5,8]`, exponential cutoff sweep `oct/s=0 [−8,8]`; HP cutoff `20 [20,8000] Hz`, sweep same bounds. Modulate coefficients per 32 samples. Defaults imply no active phaser, repeat, pitch jump, or sweeps. [R1,R4]

Preset generator: start from these defaults, draw each listed field **uniformly in the indicated physical range** from a per-event PRNG; draw wave choice uniformly from the set. Unlisted parameters keep defaults. `T=A+S+D`, constrained to the stated duration range by drawing `S,D` within the row ranges and rescaling only those two if needed. The ranges below are proposed timbres, **not historical sfxr preset data**. The right column is a per-preset unit-test oracle in addition to global determinism, finite output, no >±1 pre-mix peaks, and bounded duration. [R4]

The laser preset's extended slide is a deliberate exception to the general UI range; validator permits `−14..8` if that preset is selected. For exact preset reproducibility, fix PRNG draw order and store a versioned preset schema. Test a zero-slide/zero-vibrato sine via FFT (`fstart` ±1 bin), envelope boundaries at `A`, `A+S`, `A+S+D`, repeat pitch reset without envelope reset, duty sweep clamp, negative `fmin` crossing termination, LP/HP magnitude response at cutoff, and phaser `m=0` exact bypass. The buffer length is `ceil(T Fs)` unless `fmin` stops it earlier. O(1) state and O(N) time per voice, except a 20-ms phaser ring and optional harmonic oscillator work.

## 3. Instruments

Per-note velocity `v∈[0,1]` (default .75), pitch `f0=440·2^((midi−69)/12)`. Use the shared phase and `T60` conventions; all modes are proposals unless a measured ratio is cited. A voice's note-off starts its release at the current sample amplitude; clamp active polyphony in the caller. [R2,R3]

| Instrument | Topology, equation and proposed parameter ranges/defaults | CPU and unit-test oracle |
|---|---|---|
| Piano [R5,R7] | Add `n=1..min(32,fNyq/f0)` sines `f_n=n f0 sqrt(1+B n²)`, `B=1e−4..4e−4` (default 2e−4; tune by register). `a_n∝v(1+0.8v·n/8)/n^1.3` with two-stage `0.7 A_T60(t;0.3..1.5 s/n^0.3)+0.3 A_T60(t;2..10 s/n^0.5)`; 2–8-ms HP hammer noise. Add 1–3 unison strings at `0,±1..3` cents, normalized. At note-off, damp over 0.08–0.4 s. Optional sympathetic held-note resonators at −30..−20 dB, decay 2–6 s (disable by default). Velocity brightens partial slope and hammer level. | O(partials×strings), precalculate angular increments. FFT peaks match `f_n` within 1 bin at long capture; high partial T60 < low; louder strike has larger >3-kHz/low-band ratio; release reaches −60 dB by bound. Summed detuned strings are an approximation, not true coupled-string two-stage physics. |
| Electric piano [R3,R8] | Chowning-style two-branch FM **design choice**: body `sin(φc+I1(t)sinφm)` with `fc:fm=1:1`, tine branch `0.15..0.35·sin(φc+I14(t)sin(14φm))` with `φm` advancing at `f0` and carrier at `f0`; `I1(0)=1..4` (2), `I14(0)=.1..1.2` (.5), both decay `I(t)=I0·A_T60(t;0.2..1.5 s)`; body amp T60 1.5–5 s. `v` raises both indices. | Four phases/trig calls plus envelope. ## Checks shared by every voice

1. For the same seed/parameters/Fs/Node major/platform, compare all `Float32Array` bytes exactly; distinct seed changes noise events but does not change deterministic tonal frequency. Check 44.1 and 48 kHz length and pitch separately. [R1,R3]
2. Assert every sample finite, duration bound, `|sample|≤1` before track mix (scale each topology by known safe gain; do not hard-clip voices), envelope continuity at note-off (`A(off+)=A(off−)` before its release ramp), and silence after requested end except declared tails. [R1]
3. Measure pitch by phase increments for synthetic fixtures or a windowed FFT with sufficiently long stable segment; avoid demanding FFT precision in 20-ms sweeps. Measure T60 by a 60-dB amplitude drop only when the rendered duration permits; otherwise compare logarithmic slopes. [R3,R5]
4. Check alias energy near Nyquist for the highest requested pitch; reject impossible modal/harmonic frequencies rather than folding them. Run preset render cost as `samples × active oscillators/filters` and avoid heap allocation in inner loops. [R3]
