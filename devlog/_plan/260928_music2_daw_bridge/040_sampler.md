## 1. SFZ ingress, subset and path contract

[V] SFZ headers/opcode inheritance, `key` shorthand, main-file-relative includes and inclusive `end`/`loop_end` are documented in R2 §1–§2 ([SFZ format](https://sfzformat.com/legacy/), [include](https://sfzformat.com/opcodes/include/)). [I] Public signatures:

```ts
export interface SfzWarning { file: string; line: number; opcode?: string; message: string }
export interface SfzRegion { sample: string; source: { file: string; line: number };
  control: { defaultPath: string; noteOffset: number; octaveOffset: number };
  key: [number,number]; velocity: [number,number];
  pitchKeycenter: number | "sample"; pitchKeytrack: number; tune: number; transpose: number;
  volume: number; amplitude: number; pan: number; offset: number; end: number | null;
  loopMode: "no_loop"|"one_shot"|"loop_continuous"|"loop_sustain"|null;
  loopStart: number|null; loopEnd: number|null; trigger: "attack"|"release"|"release_key"|"first"|"legato";
  ampeg: { delay:number; start:number; attack:number; hold:number; decay:number; sustain:number; release:number };
  ampVeltrack:number; ampVelcurve:ReadonlyMap<number,number>; group:number; offBy:number;
  offMode:"fast"|"normal"; rtDecay:number; seqLength:number; seqPosition:number; lorand:number; hirand:number }
export interface SfzInstrument { regions: readonly SfzRegion[]; warnings: readonly SfzWarning[] }
export async function parseSfz(path: string, root: string): Promise<SfzInstrument>;
export async function confinedRealpath(root: string, candidate: string): Promise<string>;
```

[I] `root` is the canonical directory containing the main `.sfz`; the song-relative `sfz:` ref is first confined to the canonical song directory (wp2's lexical POSIX path rule), then every included SFZ and sample to the main SFZ directory. Resolve symlinks with `realpath`, reject escapes even when the lexical path looks internal, and never search a user home or ambient library path. Included sample references and nested includes remain relative to the **main** SFZ directory (R2 §1.4 V). `default_path` concatenates before sample; normalize backslashes inside SFZ only. Invalid supported opcode syntax/value yields `E_PARSE` exit 2 with `{file,line,opcode}`. Escape/unreadable files yield `E_ACCESS` exit 4 with `{file}`. An unknown opcode/header produces a located warning; any feature whose absence would select the wrong region (for example `locc*`, `sw_*`, `xfin*`) disables that region with a warning, never silently plays it. A non-WAV sample disables its region with `unsupported codec` warning; zero playable regions raises `E_CAPABILITY` exit 3. This is stricter than R2's suggestion to silently drop a missing sample; an unreadable declared WAV is `E_ACCESS` (D7/F16).

[I] Serialized diagnostic `file` is relative to the main SFZ directory (POSIX separators), ordered by include-expanded source position then region position, and relayed through `RenderResult.warnings` and the CLI `warnings` array. A local absolute path may occur only in an unsaved error cause, never in an artifact.

[I] Parse UTF-8 with fatal decoding (do not reinterpret malformed bytes as Latin-1 without an explicit encoding option); CRLF normalizes to LF. `#include "…"` is expanded inline up to depth 32, with cycle detection by canonical path. `#define $NAME value` expands longest matching defined name first in source order. Strip `//` and `/*…*/` outside quoted include paths, then recognize `<control|global|master|group|region>` and `name=value`; a value may contain spaces until another ` name=` or header. `key` expands in source order to `lokey`, `hikey`, `pitch_keycenter`; a later explicit keycenter wins. New global/master/group clears that scope and lower scopes; region emission merges global→master→group→region. At each region emission, copy the then-current `<control>` values into `region.control`; initial values are `{defaultPath:"",noteOffset:0,octaveOffset:0}`. A later control changes only subsequently emitted regions, including across inline includes; do not retain a single final control state on `SfzInstrument`. Note names use IPN C4=60, A4=69 (R2 §1.5 V). Supported aliases are `pitch→tune`, `polyphony_group→group`, `loopmode/loopstart/loopend/offby→loop_mode/loop_start/loop_end/off_by`. Warn on uppercase opcode names and unsupported aliases. No code from other SFZ engines is copied (D11).

[I] Tier A implemented: `sample` (including `*silence|*sine`), `key|lokey|hikey`, `lovel|hivel`, `pitch_keycenter|pitch_keytrack`, `tune|transpose`, `volume|amplitude|pan`, `offset|end`, `loop_mode|loop_start|loop_end`, `trigger=attack|release|release_key|first|legato`, `ampeg_delay|start|attack|hold|decay|sustain|release`, `amp_veltrack|amp_velcurve_N`, `group|off_by|off_mode`, `seq_length|seq_position`, `lorand|hirand`, `rt_decay`, `#include`, `#define`, `default_path`, `note_offset|octave_offset` (R2 §3.2). `*silence` can choke; `*sine` is a bounded virtual sample for fixtures. File-embedded WAV `smpl` first loop and unity note are read without altering `readWav`'s stereo PCM return shape; metadata is parsed from the same file bytes in `sfz-render.tool.ts`. Support only forward loops. Unsupported `smpl` loop types warn and disable the loop. R2 §3.2 Tier B and Tier C remain warning-only. If a Tier B/C condition can change selection, disable the affected region with a warning.

[I] D7 explicitly requires `trigger=release`, so this phase renders release-only regions; it supersedes F20's provisional instruction to ignore them. R2 §2.2 gives the note-off semantics; a release region uses the stored attack velocity even if no attack region matched (R2 §6.3 I).

## 2. Region selection and playback

The public seam is typed without a sampler→render import. `SfzEvent` is the note subset of `VoiceEvent`, and state is one render invocation (I):

```ts
export interface SfzEvent { midi:number; velocity:number; startFrame:number; gateFrames:number; stopFrame:number; eventIndex:number; seed:number }
export interface SfzVoice { regionIndex:number; key:number; velocity:number; startFrame:number; releaseFrame:number|null; sourcePosition:number }
export interface SfzSelectionState { counters:Map<string,number>; heldKeys:Set<number>; active:SfzVoice[] }
export interface LoadedSfz { instrument:SfzInstrument; samples:ReadonlyMap<string,StereoBuffer>; smpl:ReadonlyMap<string,{unityNote:number|null; pitchFraction:number; loop:{start:number;end:number}|null}> }
export function selectSfzRegions(instrument:SfzInstrument, event:SfzEvent, state:SfzSelectionState): readonly SfzRegion[];
export function loadSfz(songPath:string, ref:string, sampleRate:number): Promise<LoadedSfz>;
export function renderSfz(events:readonly SfzEvent[], loaded:LoadedSfz, sampleRate:number, frames:number): StereoBuffer;
```

[I] Use the typed signatures above. The `state` is local to one render invocation and traverses events in `(startFrame,eventIndex,region file order)`; it owns held keys, per-(effective key, sequence length) counters and sounding voices. Convert `event.velocity` to `v=max(1,min(127,round(127*velocity)))` for note-on; an explicit zero-velocity note is silent. One `mulberry32(event.seed)` draw in [0,1) is shared by every region for that note (R2 §2.5 I); do not make selection depend on filesystem read order. For each candidate region, effective key = `event.midi + region.control.noteOffset + 12*region.control.octaveOffset`; outside 0..127 is silent. Resolve its sample with `region.control.defaultPath`, never a later control value. Match inclusive key/velocity, `lorand ≤ r < hirand`, trigger and round-robin. For each note-on, read the 1-based counter keyed by `(effectiveKey,seqLength)` once; every otherwise eligible region of that length plays iff the shared value equals `seq_position`, then advance that key/length counter once and wrap at `seq_length`. This adopts F20’s per-key Timeline-order rule over R2 §6.3’s provisional per-region rule (D1). Regions on one event layer in source order. `release`/`release_key` use the held note-on velocity and fire at note-off; `first`/`legato` use held-key state. No sustain pedal input is present in Song v1, so `release_key` and `release` fire at the same note-off. Trigger `group=G≠0` chokes earlier active voices whose `off_by=G`, before adding any of the current event's voices. `off_mode=fast` ramps to zero over 6 ms; `normal` enters DAHDSR release. These are R2 §2.2–§2.4 I choices.

[I] Per output sample source position is `p=offset+(frame-startFrame)*step`, with `step=2^(((key-pkc)*pitchKeytrack+100*transpose+tune+smplCents)/1200)*(sourceRate/outRate)`. For `pitch_keycenter=sample`, use valid WAV `smpl` unity note as `pkc`, else warn and use 60; `smplCents=100*pitchFraction/2^32` for valid `smpl` metadata (zero when absent), so the fractional pitch contributes even when keycenter is explicit (R2 §2.1/§6.4). `end` is inclusive; output stops once `p>end`. `loop_continuous` wraps the inclusive `[loop_start,loop_end]` during hold and release; `loop_sustain` wraps only before note-off; `one_shot` ignores note-off, and `no_loop` enters release. An invalid loop is warned and disabled; no infinite loop may outlive render `ctx.frames`. Source reads at a wrap are loop-aware. The normalized equal-power pan law is `θ=(pan+100)π/400`, `gL=√2 cos θ`, `gR=√2 sin θ`; stereo balances each original channel without mono folding (R2 §6.4 I). Per-voice gain is `10^((volume-releaseDecayDb)/20)*(amplitude/100)*velocityGain*env`, where `releaseDecayDb=rtDecay*heldSeconds` only for a `release`/`release_key` region triggered at note-off (`heldSeconds=(noteOffFrame-noteOnFrame)/Fs`), otherwise 0. This applies R2 §2.2's `-rt_decay*heldSeconds` dB attenuation at release-region onset, held constant over that region. Default velocity gain is `(v/127)^2` (R2 §2.6 V); optional curve points interpolate linearly, and intermediate `amp_veltrack` follows R2 §2.6's labelled I law. Saturating the final mix is the existing master stage; reject nonfinite intermediate/output with `E_RENDER`, do not hide it by clipping.

[I] Render-side adapter signatures are `isSampleInstrument(instrument:string):boolean`, `loadSampleInstrument(songPath:string,track:ResolvedTrack,sampleRate:number):Promise<{kind:"kit";kit:LoadedKit}|{kind:"sfz";sfz:LoadedSfz}>`, and `renderSampleInstrument(resource,events:readonly VoiceEvent[],frames:number):StereoBuffer`. The helper is true only for `kit:`/`sfz:`; `sfz:` requires a notes track. Preserve the existing kit mono-to-stereo duplication **after** its original `renderKit` call, without replacing its old no-FX `mixDry` path; the SFZ tag uses `mixStereo`. `renderSong` and mixer must carry only present warnings through optional result/envelope fields. The dependency direction follows `010_project_ir.md` §3: `registry/mixer → render/instrument → sampler|kit`, plus sampler’s type-only `song` import for `ResolvedClip`/`ResolvedAudioTrack`; song never imports sampler. This is the boundary move chosen over teaching built-in `VoiceSpec` to decode files (F8/F11/F13 I).

[I] DAHDSR evaluates at output rate: delay 0; attack linear from `ampeg_start/100` to 1; hold 1; decay multiplier `exp(-8/(decay*Fs))` down to sustain; release from current level with `exp(-8/(release*Fs))`, forced 0 after release seconds. A zero-time stage jumps to its endpoint. `one_shot` ignores note-off but still obeys finite sample end. At any point cap writes by `ctx.frames` and mono next-onset `event.stopFrame` where applicable (V `src/render/mixer.tool.ts:36-59`; R2 §6.5 I). Cache raw decoded stereo PCM, not pitched copies; cap total decoded PCM in one render at 512 MiB (`E_CAPABILITY` exit 3, F20). Preserve left/right even for a mono source (`readWav.sourceChannels`, V `src/audio-io/wav.tool.ts:72-80`).

## 3. Resampling and time-scale modification

[V] R4 §1/§7.A records the bandlimited-resampling cutoff rule from JOS and Niemitalo's Hermite polynomial. [I] `resample(src: StereoBuffer, ratio: number, opts?: {mode?:"sinc"|"hq"|"hermite"|"linear"; start?:number; frames?:number; read?: (channel:0|1,index:number)=>number}): StereoBuffer` treats `ratio` as **input frames advanced per output frame**, finite `>0`; default output frames `floor((srcLen−1−start)/ratio)+1`, with explicit `frames` for clip/voice windows. `ratio===1 && start===0` uses an exact-copy bypass. Sinc default: Kaiser 16 zero crossings per wing, A=90 dB, β=8.96, rolloff 0.90, `fc=0.45*min(1,1/ratio)` input cycles, half-width `Nz/(2fc)`, kernel `2fc*sinc(2fc*t)*Kaiser(t)`. `hq` uses Nz=32/A=100; `hermite` is four-tap Catmull–Rom fast mode; `linear` is an oracle/lo-fi mode. Use fixed 512 phases/zero crossing with linear phase interpolation or direct float64 coefficients, and one fixed summation order. Outside-sample read is zero; voice loops pass their own wrapped read callback. Default is sinc even though F20 provisionally chose Hermite: D15/R4 §7.A wins. Existing `kit:` stays linear (V `src/render/kit.tool.ts:112-121`).

[I] Shared FFT helper is internal to sampler: `fft(re:Float64Array,im:Float64Array,inverse?:boolean):void` operates in place on equal power-of-two lengths 256..4096, with `inverse` dividing by N; `hann(length:number):Float64Array` returns the fixed periodic `sin²(πn/N)` window. Invalid shapes are programmer errors (`E_INTERNAL`), while excessive input WAV frame counts are checked at the file boundary (`E_CAPABILITY`). Neither function becomes a top-level `src/index.ts` export.

[V] R4 §2.2/§7.B defines `alpha = output duration/input duration`: alpha 2 doubles length. [I] `timeStretch(src: StereoBuffer, alpha: number, opts?: {method?:"wsola"|"pv"; anchors?: readonly [number,number][]}): StereoBuffer`, output `ceil(alpha*srcFrames)` exactly, or the last output anchor sample. `alpha` accepted 0.5..2 for quality-guaranteed use, 0.25..4 as the hard clip input range; outside the quality band emit a warning and retain exact length. WSOLA default for short/percussive/mixed clips: Hann N=2048, synthesis hop=1024, search tolerance ±1024 at 44.1/48 kHz; use mono sum for offsets, coarse stride 4 then refine and choose lowest offset on ties. PV for sustained tonal clips: N=4096, hop=1024, Hann, instantaneous-frequency phase propagation with identity locking to peaks greater than ±1/±2 neighbours (R4 §2.3/§7.B). `renderClips` picks PV only for a source region ≥2 s whose mean 2048-bin spectral flatness is <0.15 and whose detector finds ≤2 onsets/s; otherwise it picks WSOLA. That classifier is an I product heuristic, deterministic from source PCM and reused FFT/onset code, not an external research threshold. Both channels share WSOLA offsets or PV peak decisions, preserving stereo placement. Normalize overlap weights, avoid a zero denominator, and bypass alpha=1 by copying source exactly. A no-pitch-change `tempo` clip uses `alpha=sourceBpm/song.bpm`; F6's `bpm/sourceBpm` is the inverse **speed** ratio, not R4's duration ratio. `fit` uses `alpha=targetSeconds/sourceSeconds`. `pitchSemitones=p` after a pitch-preserving stretch uses sinc resampling at `r=2^(p/12)` from a correspondingly extended source, then trims/pads to the clip's fixed target length; pitch changes, target duration does not. `varispeed.ratio` is an input-step multiplier and changes both speed/pitch. No automatic HP-TSM: R4 §7.B allows PV with phase locking as the second method, while HPSS would add a separate expensive implementation and test surface. Document WSOLA compression transient loss as a known quality limit (R4 §2.5 V/I).

The exact clip/audio-mix seam is (I):

[I] Use the typed clip and mix signatures above. Every clip's `tick`/`lengthTicks` from wp2 becomes absolute seconds through shared `ticksToSeconds`, then frames by `round(seconds*Fs)`; never derive placement from ProjectIR. `none`: native-rate conversion only, source offset then truncate/zero-pad to declared length. `varispeed`: source-read ratio multiplies conversion ratio. `tempo`: use source beat duration then alpha above, pitch preserved. `fit`: consume exactly `sourceSeconds` from offset and fit that region to `lengthTicks`. For a stateful insert on an audio track, render source from song origin through crop end, run insert once, then crop; do not reconstruct its state at crop start (F11 and wp6 §2). Existing output without `--force` is `E_ACCESS` exit 4; `--force` replaces only files this invocation owns, never unrelated directory contents.
