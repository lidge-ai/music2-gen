# devlog/_plan

Active implementation units live here as `YYMMDD_slug/` folders. Each unit holds numbered
documents: `000-009` research, specs and the master plan; `010-019` the first implementation
phase, `020-029` the second, and so on. A unit moves to `devlog/_fin/` when its last phase closes.
Bare names such as `PLAN.md` are not used.
